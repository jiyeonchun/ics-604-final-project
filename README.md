# From College to Career: A Statistical Analysis of Student Employability Factors

This project analyzes the Education and Career Success dataset to identify which academic, experiential, and soft skill factors most strongly predict early career outcomes including starting salary, job offers, and time to promotion. The analysis is conducted in Python using a Jupyter Notebook and covers three research questions using statistical and machine learning methods.

### Download the Dataset
Download the dataset from Kaggle and place it in the same folder as the notebook:
https://www.kaggle.com/datasets/adilshamim8/education-and-career-success

### Folder Structure
```
.
├── requirements.txt               # Required python packages with versions 
├── notebook.ipynb                 # Main analysis notebook
├── education_career_success.csv   # Dataset from Kaggle
└── README.md                      # Project documentation
```

### Environment Setup
```bash
pip install -r requirements.txt
```

### Running the Notebook
```bash
jupyter notebook
```
Open `notebook.ipynb` and run each cell sequentially from top to bottom.

> **Note:** Do not skip cells — each cell depends on variables defined in previous steps.
